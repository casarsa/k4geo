## Geometries of the MUon System for Interesting Collisions

The following MuSIC detector models are available in k4geo ( current production model is **MuSIC_v3** )

| Model         |  Description                       | Hcal   |  Ecal   | Muon | Status     |
| ------------- | -----------------------------------|--------|---------|------|------------|
| MuSIC_v2	| Production ready geometry          | Fe-Sci | CRILIN  | RPC  | validated  |
| MuSIC_v3      | Geometry with instrumented nozzles | Fe-Sci | CRILIN  | RPC  | validated  |
| MuSIC_v3.1    | MuSIC_v3 with nine ForwardTracker disks in 2 cm nozzle gaps | Fe-Sci | CRILIN  | RPC  | development |
